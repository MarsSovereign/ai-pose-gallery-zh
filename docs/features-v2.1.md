# v2.1 新功能说明

## 1. 多视角设定图 / 批量换姿势（合成台 → 4）

- **多视角设定图**：先从姿势库选一个姿势，锁定当前人像和服装，一键把这个姿势的全部视角（正面 / 俯视 / 仰视 / 侧面 / 斜侧）各生成一张，自动拼成一张带标注的角色设定图。
- **同一角色批量换姿势**：范围可选「同动作分类 / 同体系 / 我收藏的姿势 / 全部」，视角可选「同视角 / 只要正面 / 任意」，一次 4–40 张。适合做角色 LoRA 训练集或短剧多镜头素材。
- 逐张串行生成（ComfyUI 显存、云端接口限流都更稳），可随时「停止」；每张结果都会进生成记录。

## 2. 人物卡（合成台 → 4）

「导出人物卡 ZIP」包含：

| 文件 | 内容 |
| --- | --- |
| `character.json` | 机器可读：名称、说明、画风、角色 DNA、提示词、参考图与结果清单 |
| `人物卡.md` | 人读版说明，含可直接粘贴的中英文「角色 DNA」 |
| `refs/` | 全部参考图（人像 / 服装 / 姿势 / 场景 / 表情 / 道具 / 附加） |
| `images/` | 设定图与批量结果（没有批量结果时导出当前结果图） |

「导入人物卡」可还原整套配方：图库条目按 ID 还原，本机上传的图片从 ZIP 中恢复。

## 3. 图生视频（合成台 → 5，本地 ComfyUI）

1. 在 ComfyUI 打开你的图生视频工作流（H3、Wan 等）→「工作流 → 导出 (API)」。
2. 在合成台「导入视频工作流」，系统会自动识别首帧 `LoadImage` 节点和正向提示词节点（可手动改）。
3. 运动提示词默认带上角色 DNA，可改写；点「用当前结果生成视频」。
4. 支持 VideoHelperSuite（`VHS_VideoCombine`，输出在 `gifs` 字段）与官方 `SaveVideo` / `SaveWEBM` / 动图输出。

## 4. 骨架控制（ComfyUI 预设，实验性）

工作流模板选「Qwen Image Edit 2509 三图合成 + DWPose 骨架控制」：姿势图先经 `DWPreprocessor` 提取人体骨架，骨架图同时作为图3 送入视觉语言编码器与像素参考（`ReferenceLatent`），动作还原度更高，也不会照搬人偶的关节球。

- 需要安装自定义节点 [comfyui_controlnet_aux](https://github.com/Fannovel16/comfyui_controlnet_aux)（ComfyUI Manager 搜索 `controlnet_aux`），首次运行会自动下载 DWPose 模型（yolox_l.onnx、dw-ll_ucoco_384_bs5.torchscript.pt）。
- 选择此预设后提示词会自动改成「按骨架摆姿势、不要画出骨架线」。
- 「检测本机模型」会提示是否缺少节点。

## 5. 提示词语言与自定义画风

- 合成台「提示词语言」可切换中文 / English（英文版会带上服装库的英文关键词）。
- 「API 接口配置」页可新增 / 编辑 / 删除自定义画风，可基于内置画风改写；自定义画风以 ★ 开头出现在画风下拉框中。

## 6. 我的素材库（`/library`）与扩展槽位

- 上传并长期保存自己的 **人像 / 服装 / 姿势 / 场景 / 表情 / 道具**，可改名、写备注（备注会写进提示词）、改类型。数据保存在浏览器 IndexedDB，不会上传。
- 合成台三个核心槽位都多了「从素材库选」按钮；新增 **场景 / 表情 / 道具** 三个可选槽位，上传的图片会同时存入素材库。
- 生成结果可一键「存入素材库」作为人像，用来锁定同一个角色反复使用。
- 注意：内置 ComfyUI 工作流只有人像 / 服装 / 姿势三个图片输入，场景 / 表情 / 道具 / 附加图在云端多图接口（Gemini、GPT Image、千问、豆包）中生效；ComfyUI 需使用自定义工作流。

## 7. AI 语义搜索 / 以图搜图 / 找相似

- 三个图库页的「AI 语义搜索」：用一句话描述（如「坐在地上抱着膝盖」「白色衬衫配牛仔短裤」「黑色长直发齐刘海」），或上传一张图以图搜图。
- 大图预览里的「找相似」直接用预计算向量，无需下载模型，秒出结果。
- 基于 Chinese-CLIP（`Xenova/chinese-clip-vit-base-patch16`，q8 量化）在浏览器本地运行，首次需下载约 182 MB 模型，之后浏览器缓存。
- 模型默认经本站 `/hf/*` 同源转发（本地 `pnpm dev` 与 Cloudflare 部署都支持）到 hf-mirror.com，可在「API 接口配置」切换。
- 图库向量：`data/clip-index.json` + `data/clip-index.bin`（4,345 × 512 维 int8，约 2.2 MB）。新增图片后运行：

```bash
node scripts/build_clip_index.mjs
```

国内网络可先设置 `HF_ENDPOINT=https://hf-mirror.com`。

## 8. 收藏与分享链接

- 每张卡片右下角的星标收藏，图库工具条「只看收藏」；批量换姿势可直接用收藏的姿势。
- 合成台「分享」复制一个链接，打开即还原人像 / 服装 / 姿势与画风（本机上传的图片无法放进链接，会提示）。

## 9. ComfyUI 插件新节点

| 节点 | 作用 |
| --- | --- |
| **AI 姿势批量遍历 (Pose Batch)** | 按体系 / 分类 / 视角筛选，输出姿势图 **列表** 与中英文姿势提示词列表。下游节点会对每张姿势图各执行一次：固定人像 + 服装，一次排队批量出图 |
| **保存 LoRA 训练集 (图片+打标)** | 把批量结果按 `0001.png` + `0001.txt`（触发词 + 打标文本）保存到 ComfyUI `output/` 下的指定文件夹 |

另外修复了插件在 Windows 上路径校验误判（原代码按 `/` 拼接判断）导致图片无法加载的问题。

## 10. MCP 服务（`mcp_server/server.py`）

零依赖（Python 3.9+），让 Claude Code 等 Agent 直接检索图库、拼提示词、调用本机 ComfyUI 出图：

```bash
claude mcp add pose-gallery -e COMFYUI_URL=http://127.0.0.1:8000 -- python /绝对路径/ai-pose-gallery-zh/mcp_server/server.py
```

| 工具 | 说明 |
| --- | --- |
| `search_gallery` | 中文关键词检索三库（默认排除 18+），返回 ID 与本地图片绝对路径 |
| `list_categories` | 列出分类 / 体系 / 视角 / 标签 / 发型 |
| `get_item` | 按 ID 取完整元数据 |
| `build_recipe_prompt` | 组装中 / 英文多图合成提示词，返回按图1/2/3 排好的参考图路径 |
| `random_recipe` | 随机一套配方 |
| `comfyui_generate` | 用 Qwen Image Edit 2509 三图工作流在本机 ComfyUI 出图，保存到 `output/`（可用 `POSE_GALLERY_OUTPUT` 改） |
